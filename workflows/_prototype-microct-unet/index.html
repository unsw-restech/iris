microCT Segmentation (2D U-Net)

Train a U-Net on a handful of labelled slices, then segment your whole reconstructed scan with it, all in one job. You get a 3D label volume, the trained weights, and per-class Dice and IoU scores logged so you can compare runs.

Input
netCDF blocks + 5–30 labelled TIFF slices
Output
3D label TIFF
Compute
1 GPU, any type
Typical run
? h (TBC)

1. Before you start: get your data into scratch

Once per dataset. Arrange it like this on your computer:

my-scan/ volume/ all block*.nc files of one scan train/ images/ 2D TIFF slices, same dtype as the volume labels/ same file names as images/; 0 = unlabelled

Then copy it to your scratch through the data mover:

rsync -av --progress my-scan/ zID@kdm.restech.unsw.edu.au:/srv/scratch/zID/my-scan/

On Windows: WinSCP to the same host and folder. Your scratch holds 128 GB, about seven 16 GB scans.

2. Run it

▶  Run on Katana Opens Katana OnDemand — log in with your zID when prompted.
  1. Pick your Dataset folder (e.g. /srv/scratch/zID/my-scan). The form checks its layout before submitting.
  2. Optionally give an Experiment name to group runs you want to compare.
  3. Click Submit. Everything else has a working default.
  4. On later runs, use Load parameters in the form's history to start from a previous run.

Parameters

ParameterDefaultDescription
dataset—Your dataset folder in scratch
experiment_namemicroct-segmentationGroups runs in your tracking store
epochs50Passes over the training patches
patch_size256Square patch side, pixels
learning_rate0.001Adam learning rate
val_percent20Patches held out for Dice/IoU
ngpus / ncpus / mem1 / 8 / 32gbResources
walltime04:00Maximum run time

3. See your results

Everything lands in my-scan/runs/<job ID>/:

FileDescription
labels.tif3D label volume, one uint8 slice per z, opens in napari or Fiji
model.ptTrained weights
metrics.jsonPer-class Dice and IoU, per epoch and final
params.jsonEvery setting, including the split seed
commit.txtThe code version that ran

The job's output file, my-scan/runs/<job ID>.OU, ends with the exact command to view it. To open it:

  1. In OnDemand, start a Virtual Desktop: CPU only, 4 cores, 16 GB, 4 hours.
  2. Open a terminal in the desktop and paste the iris-view … line. Or run iris-view alone to pick from recent runs.
  3. Scroll through slices with the labels over the raw scan.
  4. To compare runs, run iris-compare in the same desktop.

For 3D, open a cropped region in ParaView (module load paraview). Fiji opens labels.tif on its own. To copy results home, swap the rsync source and destination.

microCT Segmentation (2D U-Net)

Segment a full microCT scan from 5–30 slices you've labelled in Dragonfly or any tool.

Your dataset folder

This folder is the whole interface. Get it into your scratch once and every run reads from it and writes back into it.

/srv/scratch/zID/my-scan/ volume/ block00000000.nc … block00000031.nc train/ images/ z0640.tif z0700.tif … labels/ z0640.tif z0700.tif … same names, 0 = unlabelled runs/ 1234567.kman.restech.unsw.edu.au/ ← each run lands here
rsync -av --progress my-scan/ zID@kdm.restech.unsw.edu.au:/srv/scratch/zID/my-scan/   # or WinSCP

You're ready when

  • The folder is under /srv/scratch/zID
  • volume/ has the scan's .nc blocks
  • train/images and train/labels hold the same file names

The form checks all three and tells you which failed.

▶  Run on Katana

Pick the folder → Submit. That's it.

After you submit

Queued, then running

Usually a few hours in total. You get an email when it ends.

Open the job output

In your Files app: my-scan/runs/<job ID>.OU. The last line is iris-view /srv/scratch/zID/my-scan/runs/<job ID>.

Start a Virtual Desktop

CPU only, 4 cores, 16 GB, 4 hours. Open a terminal and paste that line.

Compare with earlier runs

Run iris-compare in the same desktop: Dice and IoU per class, side by side.

Tuning

Defaults are a reasonable first run. Change one thing at a time and keep the same Experiment name, so iris-compare shows what helped.

Epochs (50) · Patch size (256) · Learning rate (0.001) · Validation % (20). Resources and seed are under Advanced.

Other viewers and copying results home

ParaView for 3D on a cropped region; Fiji opens labels.tif. To copy home, swap the rsync arguments.
