Variant Calling (GATK4)

Germline short variant discovery following GATK Best Practices via nf-core/sarek. Supports whole genome (WGS) and whole exome (WES) sequencing on human reference genomes.

▶  Run on Katana Opens Katana OnDemand — log in with your zID when prompted.
Version
v1.4.2
Engine
nf-core/sarek
Compute
Katana
CPUs (default)
8

What to expect

  1. Click Run on Katana and log in with your zID.
  2. Set the path to your BAM or CRAM input directory.
  3. Select your reference genome and sequencing type (WGS or WES).
  4. If running WES, provide the path to your target intervals BED file.
  5. Set your output directory to your scratch space.
  6. Adjust walltime and memory, then click Submit.

Parameters

ParameterDefaultDescription
bam_dir—Path to directory containing aligned BAM or CRAM files
genomeGRCh38Reference genome — GRCh38 or GRCh37
sequencing_typeWGSSequencing type — WGS or WES
intervals—Target intervals BED file (WES only, leave blank for WGS)
outdir—Output directory — use your scratch space

mem32gbMemory allocation
walltime24:00Maximum walltime (hours:minutes)
