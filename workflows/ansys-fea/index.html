Finite Element Analysis (ANSYS)

Structural, thermal and modal finite element analysis in batch mode. Suited to parameter sweeps and mesh convergence studies too large to sit through interactively — submit the sweep, collect the results table. Uses UNSW's licensed ANSYS installation.

▶  Run on Katana Opens Katana OnDemand — log in with your zID when prompted.
Version
v2025R2
Engine
ANSYS
Compute
Katana
CPUs (default)
8

What to expect

  1. Click Run on Katana and log in with your zID.
  2. Point input at your APDL input file or Workbench journal.
  3. Set the analysis type — static structural, thermal or modal.
  4. Define any parameter sweep values to run across.
  5. Set your output directory to your scratch space.
  6. Adjust walltime and resources if needed, then click Submit.

Parameters

ParameterDefaultDescription
input—ANSYS APDL input file (.dat) or Workbench journal
analysisstaticAnalysis type — static, thermal, modal, harmonic
sweepnoneParameter values to sweep, as a comma-separated list
outdir—Output directory — use your scratch space
ncpus8Number of CPU cores — check your licence's parallel entitlement
mem32gbMemory allocation — raise it for large meshes
walltime12:00Maximum walltime (hours:minutes)

Outputs

OutputDescription
*.rstResults file — stresses, strains, displacements
results_summary.csvKey quantities per sweep point
*.outSolver output, including convergence history
mesh_stats.txtElement counts and mesh quality metrics

Environment

Runs on Katana with module load ansys/2025R2. Nothing is installed into your home directory. ANSYS is licensed to UNSW; jobs check out a licence at run time and may queue if all seats are in use.
