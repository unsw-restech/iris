LLM Batch Inference (vLLM)

Run an open-weight language model over a corpus on UNSW GPUs — classification, extraction, summarisation or scoring at scale. Because inference happens on Katana, sensitive or ethics-restricted text never leaves the university, which commercial APIs cannot offer.

▶  Run on Katana Opens Katana OnDemand — log in with your zID when prompted.
Version
v0.18.0
Engine
vLLM
Compute
Katana GPU
GPU (default)
1x

What to expect

  1. Click Run on Katana and log in with your zID.
  2. Point input_file at your prompts, one JSON record per line.
  3. Choose the model to serve from a local weights directory.
  4. Set the sampling parameters — temperature, maximum tokens.
  5. Set your output directory to your scratch space.
  6. Adjust walltime and resources if needed, then click Submit.

Parameters

ParameterDefaultDescription
input_file—JSONL file of prompts to process
model—Path to model weights in your scratch space
max_tokens512Maximum tokens to generate per prompt
temperature0.0Sampling temperature — 0 is deterministic
batch_sizeautoRequests batched together; vLLM schedules automatically
outdir—Output directory — use your scratch space
ngpus1Number of GPUs — larger models need more
walltime12:00Maximum walltime (hours:minutes)

Outputs

OutputDescription
completions.jsonlModel output, one record per input prompt
metrics.jsonThroughput, token counts and total runtime
failed.jsonlPrompts that errored, for retrying
vllm.logServer log including model load and batching behaviour

Environment

Runs on Katana with module load vllm/0.18.0. Nothing is installed into your home directory. Model weights are not downloaded for you — stage them in your scratch space first.
