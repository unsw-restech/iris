Cell Segmentation (Cellpose)

Automated cell and nucleus segmentation from fluorescence microscopy using Cellpose's generalist deep-learning models. Handles varied cell types and imaging conditions without retraining, and outputs masks plus per-cell morphometrics for batches of images.

▶  Run on Katana Opens Katana OnDemand — log in with your zID when prompted.
Version
v1.1.0
Engine
Cellpose
Compute
Katana GPU
GPU (default)
1x

What to expect

  1. Click Run on Katana and log in with your zID.
  2. Point image_dir at your microscopy images.
  3. Choose a model — cyto3 for whole cells, nuclei for nuclei only.
  4. Set the expected cell diameter in pixels, or leave it to be estimated.
  5. Set your output directory to your scratch space.
  6. Adjust walltime and resources if needed, then click Submit.

Parameters

ParameterDefaultDescription
image_dir—Directory of microscopy images (TIFF, PNG)
modelcyto3Cellpose model — cyto3, cyto2, nuclei
diameterautoExpected cell diameter in pixels; auto-estimates when unset
channels0,0Segmentation and nuclear channel indices
outdir—Output directory — use your scratch space
ncpus8Number of CPU cores
ngpus1Number of GPUs — strongly recommended for large batches
walltime04:00Maximum walltime (hours:minutes)

Outputs

OutputDescription
*_masks.pngLabel mask per input image, one integer per cell
*_seg.npyCellpose segmentation object, for reloading in the GUI
morphometrics.csvPer-cell area, perimeter, eccentricity and centroid
summary.csvCell counts per image

Environment

Runs on Katana with module load python/3.10.8. Nothing is installed into your home directory. Cellpose has no Katana module, so the job creates a virtual environment in your scratch space on first run and installs it there — the one workflow in this catalogue that does.
