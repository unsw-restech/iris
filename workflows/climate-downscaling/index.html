Regional Climate Downscaling

Statistical downscaling of CMIP6 global climate models to 5km Australian regional grids. Supports temperature and precipitation variables across multiple emissions scenarios.

▶  Run on Katana Opens Katana OnDemand — log in with your zID when prompted.
Version
v0.9.0
Engine
Python/BCSD
Compute
Katana
CPUs (default)
8

What to expect

  1. Click Run on Katana and log in with your zID.
  2. Set the path to your CMIP6 NetCDF input directory.
  3. Select your CMIP6 model, emissions scenario, and climate variable.
  4. Set the start and end years for downscaling.
  5. Set your output directory to your scratch space.
  6. Adjust walltime and memory, then click Submit.

Parameters

ParameterDefaultDescription
input_dir—Path to directory containing CMIP6 NetCDF files
cmip6_modelACCESS-CM2Global climate model to downscale
scenariossp370Emissions scenario — ssp126, ssp245, ssp370, ssp585
variabletasmaxClimate variable — tasmax, tasmin, pr
start_year2020Start year for downscaling
end_year2050End year for downscaling
outdir—Output directory — use your scratch space
walltime12:00Maximum walltime — increase for longer date ranges
