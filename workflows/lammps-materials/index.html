Materials Modelling (LAMMPS)

Classical molecular dynamics for materials — mechanical properties, thermal transport, diffusion and phase behaviour. LAMMPS scales across nodes, so systems from thousands to millions of atoms are practical.

▶  Run on Katana Opens Katana OnDemand — log in with your zID when prompted.
Version
v2024.02
Engine

8

What to expect

  1. Click Run on Katana and log in with your zID.
  2. Point input at your LAMMPS input script.
  3. Supply any potential files the script references.
  4. Set the number of timesteps and thermodynamic output frequency.
  5. Set your output directory to your scratch space.
  6. Adjust walltime and resources if needed, then click Submit.

Parameters

ParameterDefaultDescription
input—LAMMPS input script (in.*)
potential—Interatomic potential file, if not bundled with LAMMPS
nsteps100000Number of timesteps
outdir—Output directory — use your scratch space
ncpus16Number of CPU cores — LAMMPS is MPI-parallel
mem32gbMemory allocation
walltime24:00Maximum walltime (hours:minutes)

Outputs

OutputDescription
dump.*Atom trajectories for visualisation in OVITO or VMD
log.lammpsThermodynamic output per timestep
restart.*Restart files for continuing the simulation
properties.csvDerived properties — temperature, pressure, energy

Environment

Runs on Katana with module load lammps/20240207. Nothing is installed into your home directory.
