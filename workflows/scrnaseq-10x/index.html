Single-cell RNA-seq (10x)

Process 10x Genomics single-cell RNA-seq runs with Cell Ranger — demultiplexing, alignment, barcode counting and feature-barcode matrices, ready for downstream analysis in Seurat or Scanpy. Handles multi-sample projects in one submission.

▶  Run on Katana Opens Katana OnDemand — log in with your zID when prompted.
Version
v9.0.1
Engine
Cell Ranger
Compute
Katana
CPUs (default)
8

What to expect

  1. Click Run on Katana and log in with your zID.
  2. Point fastq_dir at your 10x FASTQ directory.
  3. Select the reference transcriptome — human or mouse.
  4. Set the expected number of recovered cells, or leave it to be estimated.
  5. Set your output directory to your scratch space.
  6. Adjust walltime and resources if needed, then click Submit.

Parameters

ParameterDefaultDescription
fastq_dir—Directory of 10x FASTQ files
sample—Sample name prefix, as used by cellranger count
referenceGRCh38-2024-AReference transcriptome — GRCh38 or mm10
expect_cellsautoExpected recovered cells; auto-estimates when unset
outdir—Output directory — use your scratch space
ncpus16Number of CPU cores
mem128gbMemory allocation — Cell Ranger is memory-hungry
walltime24:00Maximum walltime (hours:minutes)

Outputs

OutputDescription
filtered_feature_bc_matrix/Cell-by-gene count matrix for downstream analysis
web_summary.htmlQC report — cell calling, sequencing saturation, mapping rates
possorted_genome_bam.bamPosition-sorted alignments
metrics_summary.csvPer-sample summary metrics

Environment

Runs on Katana with module load cellranger/9.0.1. Nothing is installed into your home directory.
