DFT Geometry Optimisation (ORCA)

Molecular density functional theory — geometry optimisation, frequency analysis and single-point energies for isolated molecules. For periodic solids rather than molecules, see the Quantum ESPRESSO workflow under Engineering.

▶  Run on Katana Opens Katana OnDemand — log in with your zID when prompted.
Version
v6.1.0
Engine
ORCA
Compute
Katana
CPUs (default)
8

What to expect

  1. Click Run on Katana and log in with your zID.
  2. Point input at your ORCA input file, or supply a structure and let the job build one.
  3. Choose the functional and basis set.
  4. Select the calculation type — optimisation, frequencies or single point.
  5. Set your output directory to your scratch space.
  6. Adjust walltime and resources if needed, then click Submit.

Parameters

ParameterDefaultDescription
input—ORCA input file (.inp), or a structure in XYZ format
methodB3LYPDensity functional — B3LYP, PBE0, wB97X-D
basisdef2-TZVPBasis set
calculationOpt FreqCalculation type — Opt, Freq, SP, or a combination
charge_mult0 1Total charge and spin multiplicity
outdir—Output directory — use your scratch space
ncpus8Number of CPU cores — ORCA parallelises over MPI
mem32gbMemory allocation — must exceed ORCA's %maxcore total
walltime24:00Maximum walltime (hours:minutes)

Outputs

OutputDescription
*.outFull ORCA output — energies, geometry, frequencies
*.xyzOptimised geometry
*.hessHessian, for thermochemistry and IR spectra
summary.txtFinal energy, convergence status and any imaginary frequencies

Environment

Runs on Katana with module load orca/6.1.0. Nothing is installed into your home directory.
