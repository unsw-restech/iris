Terrain & Hydrology (GRASS)

Terrain and hydrological analysis from digital elevation models — slope, aspect, flow accumulation, catchment delineation and stream network extraction. Used in flood modelling, erosion studies and catchment management.

▶  Run on Katana Opens Katana OnDemand — log in with your zID when prompted.
Version
v7.6.1
Engine
GRASS GIS
Compute
Katana
CPUs (default)
8

What to expect

  1. Click Run on Katana and log in with your zID.
  2. Point dem at your digital elevation model.
  3. Choose the analyses to run — terrain derivatives, hydrology, or both.
  4. Set the flow accumulation threshold defining a stream.
  5. Set your output directory to your scratch space.
  6. Adjust walltime and resources if needed, then click Submit.

Parameters

ParameterDefaultDescription
dem—Digital elevation model raster
analysesterrain,hydrologyAnalyses to run
threshold1000Flow accumulation cells required to define a stream
fill_sinkstrueFill depressions before routing flow
outdir—Output directory — use your scratch space
ncpus4Number of CPU cores
mem32gbMemory allocation — raise it for high-resolution DEMs
walltime06:00Maximum walltime (hours:minutes)

Outputs

OutputDescription
slope.tif, aspect.tifTerrain derivatives
flow_accumulation.tifAccumulated upstream flow per cell
streams.gpkgExtracted stream network as vector lines
catchments.gpkgDelineated catchment polygons

Environment

Runs on Katana with module load grass/7.6.1. Nothing is installed into your home directory.
