Particle Transport (Geant4)

Monte Carlo simulation of particles passing through matter — detector response, radiation shielding and medical physics dosimetry. Geant4 models the full interaction chain from primary particle to energy deposition.

▶  Run on Katana Opens Katana OnDemand — log in with your zID when prompted.
Version
v11.0.3
Engine
Geant4
Compute
Katana
CPUs (default)
8

What to expect

  1. Click Run on Katana and log in with your zID.
  2. Point application at your compiled Geant4 application.
  3. Supply the macro file defining geometry, physics list and primary particles.
  4. Set the number of events to simulate.
  5. Set your output directory to your scratch space.
  6. Adjust walltime and resources if needed, then click Submit.

Parameters

ParameterDefaultDescription
application—Compiled Geant4 executable
macro—Geant4 macro (.mac) with geometry and beam definition
events1000000Number of primary events
seedautoRandom seed — set it for a reproducible run
outdir—Output directory — use your scratch space
ncpus16Number of CPU cores — Geant4 multithreads over events
mem16gbMemory allocation
walltime24:00Maximum walltime (hours:minutes)

Outputs

OutputDescription
*.rootHit and scoring data, for analysis in ROOT
dose_map.csvEnergy deposition per scoring volume
run_summary.txtEvent counts, CPU time and physics process tallies
*.logFull simulation log

Environment

Runs on Katana with module load geant4/11.0.3. Nothing is installed into your home directory.
