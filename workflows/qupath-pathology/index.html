Digital Pathology (QuPath)

Batch whole-slide image analysis with QuPath running headless — tissue detection, cell counting, stain deconvolution and positive-cell scoring across slide cohorts too large to process interactively on a workstation.

▶  Run on Katana Opens Katana OnDemand — log in with your zID when prompted.
Version
v0.5.1
Engine
QuPath
Compute
Katana
CPUs (default)
8

What to expect

  1. Click Run on Katana and log in with your zID.
  2. Point slide_dir at your whole-slide images.
  3. Supply a QuPath script defining the analysis to apply to every slide.
  4. Set the pixel size or magnification the analysis assumes.
  5. Set your output directory to your scratch space.
  6. Adjust walltime and resources if needed, then click Submit.

Parameters

ParameterDefaultDescription
slide_dir—Directory of whole-slide images (SVS, NDPI, TIFF)
script—QuPath Groovy script applied to each slide
project—Existing QuPath project to add slides to, if you have one
downsample1.0Downsample factor — raise it to speed up large cohorts
outdir—Output directory — use your scratch space
ncpus8Number of CPU cores
mem32gbMemory allocation — whole-slide images are large
walltime08:00Maximum walltime (hours:minutes)

Outputs

OutputDescription
measurements.tsvPer-object measurements exported by the script
annotations.geojsonDetected regions and annotations, for reimport
summary.csvPer-slide object counts and area statistics
qupath.logRun log, including any per-slide failures

Environment

Runs on Katana with module load qupath/0.5.1. Nothing is installed into your home directory.
