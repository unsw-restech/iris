AlphaFold2 Batch

Batch protein structure prediction with AlphaFold2. Supports monomer and multimer prediction modes. A GPU node is strongly recommended for reasonable runtimes.

▶  Run on Katana Opens Katana OnDemand — log in with your zID when prompted.
Version
v2.3.1
Engine
AlphaFold2
Compute
Katana GPU
GPU (default)
1x

What to expect

  1. Click Run on Katana and log in with your zID.
  2. Set the path to your input FASTA file.
  3. Select a prediction mode — Monomer for single chains, Multimer for protein complexes.
  4. Set the max template date and output directory.
  5. Under advanced options, confirm GPU is set to 1.
  6. Adjust walltime based on sequence length, then click Submit.

Parameters

ParameterDefaultDescription
fasta_file—Path to input FASTA file containing protein sequence(s)
prediction_modemonomerPrediction mode — monomer, monomer_ptm, multimer
max_template_date2024-01-01Templates released after this date will not be used
outdir—Output directory — use your scratch space
ncpus8Number of CPU cores
mem64gbMemory allocation — increase for large multimers
ngpus1Number of GPUs — strongly recommended
walltime24:00Maximum walltime — allow 4-24h depending on sequence length
