RNA-seq Pipeline

Bulk RNA-seq from FASTQ to differential expression using nf-core/rnaseq. Supports human and mouse reference genomes, paired-end reads, and automatic strandedness detection.

▶  Run on Katana Opens Katana OnDemand — log in with your zID when prompted.
Version
v2.1.0
Engine
nf-core/rnaseq
Compute
Katana
CPUs (default)
8

What to expect

  1. Click Run on Katana and log in with your zID.
  2. Set the path to your FASTQ input directory using the file browser.
  3. Select your reference genome and strandedness.
  4. Set your output directory to your scratch space.
  5. Adjust walltime and memory if needed, then click Submit.
  6. Results will appear in your output directory when the job completes.

Parameters

ParameterDefaultDescription
reads_dir—Path to directory containing your FASTQ files
reads_pattern*_R{1,2}.fastq.gzGlob pattern matching your FASTQ filenames
genomeGRCh38Reference genome — GRCh38, GRCh37, GRCm39, GRCm38
strandednessautoLibrary strandedness — auto, forward, reverse, unstranded
outdir—Output directory — use your scratch space
ncpus8Number of CPU cores
mem32gbMemory allocation
walltime12:00Maximum walltime (hours:minutes)
