fMRI Preprocessing (fMRIPrep)

Standardised functional MRI preprocessing — motion correction, susceptibility distortion correction, coregistration, normalisation to a template and confound extraction. BIDS in, BIDS-derivatives out, with a visual QC report per subject.

▶  Run on Katana Opens Katana OnDemand — log in with your zID when prompted.
Version
v23.0.0
Engine
fMRIPrep
Compute
Katana
CPUs (default)
8

What to expect

  1. Click Run on Katana and log in with your zID.
  2. Point bids_dir at your BIDS-formatted dataset.
  3. Select the participants to process, or leave it to run the whole cohort.
  4. Choose the output spaces — for example MNI152NLin2009cAsym and T1w.
  5. Set your output directory to your scratch space.
  6. Adjust walltime and resources if needed, then click Submit.

Environment

Runs on Katana with module load neurodesk/fmriprep/23.0.0. Nothing is installed into your home directory. Neurodesk provides the tool as a container image managed for you.
