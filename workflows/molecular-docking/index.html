Molecular Docking (AutoDock Vina)

Virtual screening of ligand libraries against a protein target. Vina scores and ranks binding poses within a defined search box, parallelising naturally across the library — a standard first step in structure-based drug discovery.

▶  Run on Katana Opens Katana OnDemand — log in with your zID when prompted.
Version
v1.2.5
Engine
AutoDock Vina
Compute
Katana
CPUs (default)
8

What to expect

  1. Click Run on Katana and log in with your zID.
  2. Point receptor at your prepared protein structure (PDBQT).
  3. Point ligands at your ligand library directory.
  4. Define the search box centre and size around the binding site.
  5. Set your output directory to your scratch space.
  6. Adjust walltime and resources if needed, then click Submit.

Parameters

ParameterDefaultDescription
receptor—Prepared receptor structure in PDBQT format
ligands—Directory of ligands to screen, in PDBQT format
center—Search box centre as x,y,z in angstrom
size20,20,20Search box dimensions in angstrom
exhaustiveness8Search thoroughness — raise for better sampling, at a cost
outdir—Output directory — use your scratch space
ncpus16Number of CPU cores — Vina scales well across the library
walltime12:00Maximum walltime (hours:minutes)

Outputs

OutputDescription
*_out.pdbqtPredicted binding poses per ligand, best first
scores.csvBinding affinities in kcal/mol, ranked across the library
top_hits.csvHighest-scoring ligands, for follow-up
vina.logPer-ligand run log

Environment

Runs on Katana with module load autodock-vina/1.2.5. Nothing is installed into your home directory.
