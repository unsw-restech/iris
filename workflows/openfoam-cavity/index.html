CFD Simulation (OpenFOAM)

Lid-driven cavity flow solved with icoFoam — the standard first case in computational fluid dynamics. The case is copied from OpenFOAM's own bundled tutorials, so no input data is needed and the whole run completes in well under a minute. A working starting point for your own geometry and solver.

▶  Run on Katana Opens Katana OnDemand — log in with your zID when prompted.
Version
v1.0.0

What to expect

  1. Click Run on Katana and log in with your zID.
  2. No input data is needed — the cavity case ships with OpenFOAM and is copied into your output directory.
  3. Set your output directory to your scratch space.
  4. Change case if you want a different bundled tutorial, or point it at your own case directory.
  5. Leave the solver as icoFoam unless your case needs another one.
  6. Set walltime, then click Submit. The job runs blockMesh, then the solver.

Parameters

ncpus4Number of CPU cores — the cavity case is serial, raise it for decomposed cases

walltime00:20Maximum walltime — the cavity tutorial finishes in seconds

Outputs

OutputDescription
0.1/, 0.2/ …Time directories holding the velocity and pressure fields at each written step
constant/polyMesh/The mesh generated by blockMesh
system/Case control, discretisation and solver settings — edit these to adapt the case
*.logSolver residuals per time step, for checking convergence

Run it without OnDemand

The job script is in the repository and can be submitted directly from a Katana login node. The environment is module load openfoam; nothing is installed into your account.

cd /srv/scratch/$USER
curl -O https://raw.githubusercontent.com/PatrickTung/ares/main/workflows/openfoam-cavity/katana/ares_openfoam_cavity.pbs

qsub ares_openfoam_cavity.pbs          # meshes and solves the cavity case
