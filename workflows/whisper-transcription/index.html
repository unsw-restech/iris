Audio Transcription (Whisper)

Transcribe interviews, lectures, oral histories or fieldwork recordings to text on a GPU. Your audio never leaves UNSW — no commercial transcription service is involved, which matters for ethics-approved and sensitive recordings. If you don't supply a file, the job synthesises a short sample and transcribes that, so you can try it with no input data.

▶  Run on Katana Opens Katana OnDemand — log in with your zID when prompted.

What to expect

  1. Click Run on Katana and log in with your zID.
  2. Point audio at a file in your scratch space — or leave it empty to transcribe a synthesised sample.
  3. Choose a model size. base is a good default; medium and large are more accurate but slower.
  4. Set the language, or leave it as en.
  5. Set your output directory to your scratch space.
  6. Adjust walltime to suit the recording length, then click Submit.

Parameters

ParameterDefaultDescription
audio—Path to your audio or video file — leave empty to synthesise a sample
modelbaseModel size — tiny, base, small, medium, large
languageenSpoken language, as an ISO code
outdir—Output directory — use your scratch space
ncpus4Number of CPU cores
mem16gbMemory allocation — increase for the large model
ngpus1Number of GPUs — set to 0 for CPU, but expect it to be much slower
walltime00:30Maximum walltime — roughly real-time on CPU, far faster on GPU

Run it without OnDemand

The job script is in the repository and can be submitted directly from a Katana login node. The environment is module load whisper; nothing is installed into your account.

cd /srv/scratch/$USER
curl -O https://raw.githubusercontent.com/PatrickTung/ares/main/workflows/whisper-transcription/katana/ares_whisper_transcription.pbs

qsub ares_whisper_transcription.pbs    # transcribes a synthesised sample
