Neutronics (OpenMC)

Monte Carlo neutron and photon transport for reactor physics, criticality safety and shielding. OpenMC computes eigenvalues, flux distributions and reaction rates using continuous-energy cross sections, and runs MPI-parallel across nodes.

▶  Run on Katana Opens Katana OnDemand — log in with your zID when prompted.
Version
v0.15.0
Engine
OpenMC
Compute
Katana
CPUs (default)
8

What to expect

  1. Click Run on Katana and log in with your zID.
  2. Point model_dir at your OpenMC model — geometry, materials and settings.
  3. Set the cross-section data library location.
  4. Choose the run mode — eigenvalue or fixed source.
  5. Set your output directory to your scratch space.
  6. Adjust walltime and resources if needed, then click Submit.

Parameters

ParameterDefaultDescription
model_dir—Directory holding geometry.xml, materials.xml and settings.xml
cross_sections—Path to the cross-section data library (cross_sections.xml)
modeeigenvalueRun mode — eigenvalue or fixed source
particles100000Particles per batch
batches150Number of batches, including inactive ones
outdir—Output directory — use your scratch space
ncpus16Number of CPU cores — OpenMC is MPI and OpenMP parallel
walltime12:00Maximum walltime (hours:minutes)

Outputs

OutputDescription
statepoint.*.h5Full simulation state including all tally results
summary.h5Geometry and material summary for post-processing
keff.txtConverged multiplication factor with uncertainty
tallies.outHuman-readable tally results

Environment

Runs on Katana with module load openmc/0.15.0-mpi. Nothing is installed into your home directory.
