Metagenomics Profiling

Taxonomic and functional profiling of shotgun metagenomes. Kraken2 assigns reads to taxa, MetaPhlAn estimates species-level relative abundance, and HUMAnN maps the functional potential of the community. Suitable for microbiome studies across gut, soil and marine samples.

▶  Run on Katana Opens Katana OnDemand — log in with your zID when prompted.
Version
v2.1.2
Engine
Kraken2 + MetaPhlAn
Compute
Katana
CPUs (default)
8

What to expect

  1. Click Run on Katana and log in with your zID.
  2. Point reads_dir at your quality-trimmed FASTQ files.
  3. Choose the Kraken2 database — standard, or a custom one in your scratch space.
  4. Enable functional profiling if you want HUMAnN pathway abundances as well.
  5. Set your output directory to your scratch space.
  6. Adjust walltime and resources if needed, then click Submit.

Parameters

ParameterDefaultDescription
reads_dir—Directory of paired-end metagenomic FASTQ files
kraken_dbstandardKraken2 database to classify against
confidence0.1Kraken2 confidence threshold — raise to reduce false positives
run_humannfalseAlso run HUMAnN functional profiling — considerably slower
outdir—Output directory — use your scratch space
ncpus16Number of CPU cores
mem64gbMemory allocation — the standard database needs ~50 GB
walltime12:00Maximum walltime (hours:minutes)

Outputs

OutputDescription
kraken2_report.txtPer-sample taxonomic classification with read counts
metaphlan_abundance.tsvSpecies-level relative abundance table
humann_pathabundance.tsvPathway abundances, when functional profiling is enabled
merged_abundance.tsvAbundance table merged across all samples

Environment

Runs on Katana with module load kraken2/2.1.2. Nothing is installed into your home directory.
