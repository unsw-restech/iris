MNIST Image Classification

Train a small convolutional network to classify handwritten digits. The environment comes from Katana's PyTorch module, so there is nothing to install and no image to pull — the only download is the 11 MB dataset, which fetches itself. A worked example for your first GPU job on Katana.

▶  Run on Katana Opens Katana OnDemand — log in with your zID when prompted.
Version
v1.1.0
Engine

What to expect

  1. Click Run on Katana and log in with your zID.
  2. No input data is needed — the 11 MB MNIST dataset is downloaded automatically on first run.
  3. Set your output directory to your scratch space.
  4. Adjust epochs, batch size and learning rate if you want to experiment.
  5. Under advanced options, confirm GPU is set to 1.
  6. Set walltime, then click Submit. Training takes about a minute on a GPU, a few minutes on CPU.

Run it without OnDemand

The job scripts are in the repository and can be submitted directly from a Katana login node. Run prepare.sh once — it fetches the dataset while you still have reliable internet, so the job itself needs none. The environment is module load pytorch; nothing is installed into your account.

cd /srv/scratch/$USER
curl -O https://raw.githubusercontent.com/PatrickTung/ares/main/workflows/mnist-classification/katana/prepare.sh
curl -O https://raw.githubusercontent.com/PatrickTung/ares/main/workflows/mnist-classification/katana/ares_mnist_classification.pbs

bash prepare.sh                        # once — fetches MNIST (~11 MB)
qsub ares_mnist_classification.pbs     # submit the training job
