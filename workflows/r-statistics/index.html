Statistical Modelling (R)

Fit and compare linear models, with coefficient tables, an analysis of variance and a correlation matrix written as plain text. Base R only — no CRAN packages — so nothing is installed into your home directory. The default dataset ships with R, so it runs with no input data; point it at your own CSV when you're ready.

▶  Run on Katana Opens Katana OnDemand — log in with your zID when prompted.
Version
v1.0.0

What to expect

  1. Click Run on Katana and log in with your zID.
  2. No input data is needed — the built-in swiss dataset is used unless you set csv.
  3. To use your own data, set csv to a file in your scratch space; numeric columns are modelled.
  4. Set response to the variable you want to explain.
  5. Set your output directory to your scratch space.
  6. Adjust walltime if your dataset is large, then click Submit.

Parameters

ParameterDefaultDescription
csv—Path to your own CSV — leave empty to use a built-in dataset
datasetswissBuilt-in R dataset to use when no CSV is given
responseFertilityThe variable being modelled; all other numeric columns become predictors
outdir—Output directory — use your scratch space
ncpus2Number of CPU cores
mem8gbMemory allocation — raise it for large datasets
walltime00:15Maximum walltime (hours:minutes)

Outputs

FileDescription
model_summary.txtFull and reduced model summaries — coefficients, standard errors, R²
model_comparison.txtAnalysis of variance between the two models, plus AIC for each
coefficients.csvCoefficient table as CSV, for importing into a paper or report
correlations.txtCorrelation matrix across all numeric variables
metrics.jsonR², adjusted R², AIC and the comparison p-value in machine-readable form

Run it without OnDemand

The job script is in the repository and can be submitted directly from a Katana login node. The environment is module load r; nothing is installed into your account.

cd /srv/scratch/$USER
curl -O https://raw.githubusercontent.com/PatrickTung/ares/main/workflows/r-statistics/katana/ares_r_statistics.pbs

qsub ares_r_statistics.pbs             # fetches fit_models.R if needed
