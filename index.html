How it works Four steps to running a workflow
01 / FIND
Browse the catalogue
Filter the catalogue by research domain. Each workflow page documents its parameters, resource defaults, and how to launch it.
02 / CONFIGURE
Set your parameters
Clone the workflow repo and edit the params file. Every parameter is documented with defaults and valid ranges.
03 / RUN
Submit to compute
One command to run on Katana or Gadi. Nextflow handles job scheduling, retries, and resource allocation automatically.
04 / CITE
Cite in your paper
Citable DOIs via WorkflowHub are planned. The UNSW ResTech project is being set up and has no published workflows yet.
