#   <version> ghcr.io/unsw-restech/iris-imaging@sha256:<digest>
# CI prints the line for each image it publishes; adding it here is what
# makes that image a version. A version's line never changes, and a digest
# that a citable version's commit pins is never deleted from GHCR.
